Player portrait photos for Ludo (optional).

Put a square PNG here named after the player, in lower case, and it replaces that player's
rendered 3D portrait on the player cards, loading screen and winner screen:

  rohan.png   diya.png   ananya.png   vikram.png
  arjun.png   meera.png  kabir.png    priya.png
  alex.png    (your own profile name, if you want a photo for yourself)

rohan, diya, ananya and vikram were cropped from the Ludo UI reference image supplied for the
redesign, as were ../ludo/logo-crown.png and ../ludo/champion-crest.png.

Tips: 512 x 512 or larger, face centered, shoulders visible. Only use images you have the
rights to use. If a file is missing, the game falls back to the 3D character portrait.
